AUC = P(s₊ > s₋) + ½ P(s₊ = s₋)

s₊ is the score of a random example from class 1 (positive), s₋ the score of a random example from class 2 (negative). Every line joins one example of each class. Green: class 1 has the higher score (1), gray: a tie (½), red: class 2 higher (0). The average is the AUC, the same number as the area under the ROC curve. Drag single points, or the slider to move all of class 1. "LA: always sun" gives every example the same score.
