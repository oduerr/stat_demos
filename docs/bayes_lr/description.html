Bayesian Linear Regression

MLE vs. Posterior — Interactive Explorer

What this demo shows

Simple 1D linear regression fitted two ways: by Maximum Likelihood (OLS) and by full Bayesian inference via MCMC (Stan / NUTS). With only N = 4 observations the posterior is deliberately wide, making it easy to see how uncertainty propagates from parameters to predictions.

The interactive viewer lets you step through individual posterior samples and watch them highlighted simultaneously in the parameter space and the predictive space, so you can build intuition for what "sampling from the posterior" actually means.

The model

A normal linear regression with weakly informative priors:

  • yi ~ Normal(β₀ + β₁ xi, σ)
  • β₀, β₁ ~ Normal(0, 10)
  • σ ~ Exponential(1)

Each posterior draw is coloured by its log-likelihood log p(y | β₀, β₁, σ), so high-likelihood regions stand out immediately. The 2D scatter panels also show log-likelihood level sets (computed in-browser from the observed data), giving a direct view of the likelihood landscape the sampler explores.

How to regenerate the data

Run run_demo.py from this folder. It generates toy data, fits the Stan model, and writes three CSV files consumed by the viewer:

  • observed_data.csv — the N = 4 training points
  • posterior_samples.csv — β₀, β₁, σ, log_lik for every MCMC draw
  • posterior_predictive.csv — 500 posterior predictive draws on a prediction grid
